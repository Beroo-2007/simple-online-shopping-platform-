# Online Shopping Platform

A console-based online shopping platform developed using the C programming language to demonstrate practical applications of Data Structures.
## Project Overview
This project simulates a simple e-commerce system where different data structures are used to handle different functionalities inside the shopping platform.
## Data Structures Used
### Tree
Used to manage and display product categories.
### Queue
Used to process customer orders using FIFO (First In First Out).
### Stack
Used to store and manage browsing history.
### Linked List
Used to manage shopping cart items dynamically.
## Features
- Display product categories
- Add products to orders
- Remove processed orders
- View browsing history
- Add items to shopping cart
- Display shopping cart contents
